# Сборка настольной версии

Требуется Node.js 20+ и npm.

```bash
# 1. Собрать браузерную версию (Next.js, статический экспорт)
cd cnc-sim
npm ci
npm run build          # результат в out/

# 2. Перенести статику в оболочку
rm -rf ../cnc-desktop/renderer && mkdir -p ../cnc-desktop/renderer
cp -a out/. ../cnc-desktop/renderer/

# 3. Собрать установщик Windows
cd ../cnc-desktop
npm ci
npx electron-builder --win nsis --x64    # dist/GCodeLab-Setup-<версия>.exe
```

Оболочка (`desktop/main.js`) поднимает локальный HTTP-сервер на `127.0.0.1`
со случайным портом и раздаёт каталог `renderer/` — поэтому маршруты и
ассеты работают так же, как в браузере, но без внешних запросов.
