# G-Code Lab

Настольный симулятор стойки **Fanuc Oi**: трёхосевое фрезерование по G-коду
с реальным съёмом материала в 3D. Полноценное приложение для Windows —
устанавливается и работает без браузера и без интернета.

## Что внутри

- **Исполнение программы на глазах** — фреза снимает материал, координаты идут на DRO, кадр подсвечивается.
- **Справочник G/M-кодов Fanuc Oi** — 94 адреса и 34 разобранных примера программ.
- **Привязка контактным датчиком Renishaw OMP60** по макросам Inspection Plus (P9814, P9816, P9823, кольцо, угол, калибровка шарика).
- **Смена инструмента M06** с обязательным переходом в позицию смены, магазином на 10 гнёзд и временем смены в цикле.
- **Прижимы** — расстановка вручную или автоматически, обход прижимов при обработке.
- **Импорт детали** STL / OBJ / STEP / IGES и автогенерация управляющей программы по геометрии.
- **Библиотека программ**, инструментов и материалов, расчёт режимов резания.
- Интерфейс полностью на русском языке.

## Установка

1. Скачайте `GCodeLab-Setup-1.0.2.exe` из раздела **Releases**.
2. Запустите установщик — программа ставится в профиль пользователя, права администратора не нужны.
3. Запустите **G-Code Lab** с ярлыка на рабочем столе.

Поддерживается Windows 10 и Windows 11 (x64). Интернет для работы не нужен.
